# HomeTask 15.10.15 — HomeTask Display custom lettering

- Designed a new original rounded geometric vector alphabet inspired by the HomeTask wordmark.
- Includes uppercase A–Z, lowercase a–z, numerals 0–9, and common punctuation.
- Replaced the homepage greeting's Fredoka/Nunito substitution with locally embedded glyph rendering.
- Handles variable-length rotating customer and worker greeting text and responsive wrapping.
- Preserves accessible text for assistive technology.
- No external font dependency, no binary font file, and no change to the original logo image.
- No database, backend, or Demo Mode changes.

Note: This is a custom SVG-based web lettering system, **not** an installable TTF/OTF font. It is usable in the HomeTask website as provided. The display system does not affect regular paragraphs and controls.
