# HomeTask 15.10 — Full Portal Visual Identity

This is a SITE-WIDE visual update for the existing 15.9.1 codebase.

## Customer HomeTask
- Soft, welcoming blue-and-white surfaces, rounded cards and buttons.
- Organic decorative shapes and dotted patterns in outer page gutters.
- More spacious task dashboards, listings, section headings and forms.

## Worker Portal
- Dark navy navigation with high-contrast links.
- Structured blue-teal work canvas, grid accents and geometric gutter decorations.
- Sharper job cards, operational dashboard tiles, cleaner section divisions, task filters and work tools.

## Shared
- New role-sensitive appearance for deeper pages, not just home hero.
- Background artwork is decorative and CSS-based; no new image fetches.
- Keeps the 15.9.1 hero, existing navigation and underlying API behavior.
- Does not modify data, demo mode, payments, profile metric markup or profile ratings.
- Updated CSS/JS cache-busting in index.html to prevent stale designs.

## Installation
Replace app.js, styles.css and index.html in your current HomeTask folder. Keep all other files and demo database. Refresh with Command+Shift+R. If the server does not reload HTML automatically, restart it. Test both role views, the task map, listings, and one profile before pushing to GitHub.
