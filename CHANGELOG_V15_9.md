# HomeTask 15.9 — Distinct Customer and Worker Workspaces

## Customer / HomeTask
- Crisp white navigation and pale blue orientation strip.
- HomeTask identity with customer actions: post tasks, compare offers, get help.
- Friendly blue gradient home hero and lighter customer canvas.

## Worker Portal
- Deep navy navigation, cyan accents, readable high-contrast navigation states.
- Dedicated worker identity strip with the core worker actions.
- Work-focused teal/navy hero and cooler workspace background.

## Scope and safeguards
- Existing views, routes, tabs, profiles, database, demo data, payments and role-switching behavior are unchanged.
- Worker profile header stats and adjacent stars layout remain untouched.
- Role identity strip is automatically hidden for signed-out visitors.
- No new external assets or services.

## Installation
Apply `app.js`, `styles.css`, `index.html` and this changelog to the **existing** HomeTask folder on the development branch. Existing `RUN_DEMO.command`, demo assets and database stay in place. Refresh with Command+Shift+R and use profile menu > Switch workspace to compare the two experiences.
