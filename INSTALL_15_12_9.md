HomeTask 15.12.9 — Install

1. Stop Demo Mode or the normal server if needed.
2. Extract the ZIP.
3. Copy app.js, styles.css, and index.html into /Users/jent/HomeTask, replacing the existing three files.
4. Restart using your existing command or RUN_DEMO.command for Demo Mode.
5. Hard-refresh the browser with Command + Shift + R.

No server.py, database or demo_assets changes. Back up your existing frontend files before replacing them.
